## How to Use a Workflow

1. Open n8n and click **Import from File**
2. Select the `workflow.json` from any project folder
3. Add your own credentials (OpenAI, Google, WhatsApp, etc.)
4. Replace placeholders like `YOUR_API_KEY_HERE` and `YOUR_SHEET_ID`
5. Test and activate

> Credentials, API keys and personal data have been removed from all workflows.
